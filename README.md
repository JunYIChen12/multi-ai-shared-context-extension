# 多模型共享上下文

本仓库跟踪 `AI-REQ-20261105-001`。当前是可构建、可测试的工程基础，不是三家网页已接入的产品，也不是可替代人工复制粘贴的 MVP。

Chrome 扩展只是本仓库正在验证的**候选壳**。需求基线没有把扩展、油猴、本地中控或 Codex CLI 选定为最终方案。

## 用户已确认

- 同一问题先由 GPT/ChatGPT、Grok、Gemini **各自独立回答**，再把选定观点注入其他来源做交叉讨论。
- 优先复用用户已经登录的网页版订阅额度，不默认改成按量 API。
- 共享历史要留原文，并落到本地可读文件和机器可读记录。摘要如果以后出现，必须带来源。
- 单路失败或超时不能挡住其他路。讨论必须有停止条件。
- 云端协调和本机执行通过 Drive 四个目录交接：`01_Input_待处理`、`02_Processing_处理中`、`03_Output_交付结果`、`04_Archive_历史归档`。目录约定已经存在，自动队列还没有做。
- 目标是减少盯屏和手工复制粘贴。完成、卡住或需要确认时才打扰用户。这部分尚未实现。

Codex 额度不能当成 ChatGPT 网页版额度。

## 实现候选

| 候选 | 本仓库状态 |
| --- | --- |
| Chrome MV3 扩展壳 | 已有最小可加载目录，用来验证界面和本地导出，不是最终选型 |
| 已登录网页的受控读取 | 未做。没有内容脚本，没有站点权限 |
| 本地中控加标签页、油猴类自动化 | 未选 |
| Codex CLI 作为 GPT 一路 | 未选，且不能默认等同网页聊天额度 |
| Drive 文件队列、远程 MCP、Tailscale | 约定或候选。本仓库不连接、不常驻 |

## 本轮已实现

- TypeScript 核心契约与扩展壳分离。核心库不引用 Chrome API。
- 会话、消息、来源、轮次、状态、provider 请求和上下文选择的数据结构。
- 默认适配器明确返回**未接入**。MOCK 适配器的完成正文以 `[MOCK]` 开头，只用于演示和测试。
- 独立回答并行执行。一路抛错或超时，其他路仍留下记录。
- 第二轮只注入已完成、且被选中的其他来源，并写下「来自哪家、哪一轮、哪条消息」。未接入和失败不会被当成观点。轮次上限默认 2，最大 4。
- 导出 Markdown 与 JSONL。恢复只解析 JSONL，并强制标成未验证导入。不使用 `chrome.storage` 冒充本地文件。
- 扩展 manifest 不申请权限、不申请站点、不读 Cookie、不注入内容脚本。

## 仍未验证

- 构建会检查产物完整、权限上限和脚本语法。本环境的 Google Chrome 会忽略 `--load-extension`，所以这里没有把目录装进 `chrome://extensions`。讨论页本身不依赖扩展 API，已在 Chrome 里点过空提交、未接入、被拒绝的交叉讨论，以及 MOCK 第二轮。
- 没有登录 ChatGPT、Grok 或 Gemini，没有读取任何真实回复、登录态、配额或超时页面。
- 单元测试里的 MOCK 和未接入记录都不是三站实测。
- 没有续聊编排、取消按钮、自动重试、任务通知或 Drive 搬运。
- 导入的 `provider` 记录可以被解析，但不能证明它来自真实模型。

## 检查和构建

需要 Node.js 22 或更新版本。

```bash
npm ci
npm run check
```

`npm run check` 会依次做类型检查、单元测试和构建。CI 跑同一条命令。

单独执行：

```bash
npm run typecheck
npm run test
npm run build
```

构建输出在 `dist/extension/`。该目录被 git 忽略，需要本地重新构建。

## 加载候选壳

1. 运行 `npm run build`。
2. 打开 Chrome 的扩展管理页，启用开发者模式。
3. 加载已解压的扩展，选择 `dist/extension`。
4. 点击工具栏图标，再打开讨论页。

预期看到的是「未接入」或带 `[MOCK]` 的演示，不是三家模型的回答。「记录未接入尝试」不会访问任何网站。「运行 MOCK 演示」只在本地生成假数据。导出文件由浏览器下载保存。

## 安全边界

- 不导出 Cookie、密码、私钥或登录令牌，也不绕过登录和验证码。
- 不在用户不知情时改用按量 API。
- 不执行未经授权的对外发送、删除、付款或发布。
- 页面用文本节点显示内容，不把模型正文或导入文件当成 HTML 或指令执行。
- 不可信 JSONL 会校验结构、长度、来源枚举和原型字段。校验失败时不恢复会话。
