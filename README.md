# 多模型共享上下文

本仓库跟踪 `AI-REQ-20261105-001`。候选分支有实验性的 ChatGPT 单标签页连接器，真实网页链路尚未整体验收，也尚未发布。Gemini 单标签页实现在开放的 [PR #11](https://github.com/JunYIChen12/multi-ai-shared-context-extension/pull/11) 中，尚未合入候选。Grok 尚未实现。这不是可用产品。现行状态以 GitHub Issue 为准。

产品形态已确定为 **Google Chrome 浏览器扩展**。侧栏、弹窗或独立扩展页等界面形式，以及网页控制、上下文存储、开源/二开/自研路径仍待验证。

## 用户已确认

- 同一问题先由 GPT/ChatGPT、Grok、Gemini **各自独立回答**，再把选定观点注入其他来源做交叉讨论。
- 优先复用用户已经登录的网页版订阅额度，不默认改成按量 API。
- 共享历史要留原文，并落到本地可读文件和机器可读记录。摘要如果以后出现，必须带来源。
- 单路失败或超时不能挡住其他路。讨论必须有停止条件。
- 云端协调和本机执行通过 Drive 四个目录交接：`01_Input_待处理`、`02_Processing_处理中`、`03_Output_交付结果`、`04_Archive_历史归档`。目录约定已经存在，自动队列还没有做。
- 目标是减少盯屏和手工复制粘贴。完成、卡住或需要确认时才打扰用户。这部分尚未实现。

Codex 额度不能当成 ChatGPT 网页版额度。

## 本轮已实现

- TypeScript 核心契约与扩展壳分离。核心库不引用 Chrome API。
- 会话、消息、来源、轮次、状态、provider 请求和上下文选择的数据结构。
- 默认适配器明确返回**未接入**。MOCK 适配器的完成正文以 `[MOCK]` 开头，只用于演示和测试。
- 独立回答并行执行。一路抛错或超时，其他路仍留下记录。
- 第二轮只注入已完成、且被选中的其他来源，并写下「来自哪家、哪一轮、哪条消息」。未接入和失败不会被当成观点。轮次上限默认 2，最大 4。
- 导出 Markdown 与 JSONL。恢复只解析 JSONL，并强制标成未验证导入。不使用 `chrome.storage` 冒充本地文件。
- ChatGPT 单标签页实验连接器使用 `activeTab`、`scripting`，通过临时注入脚本连接当前标签页；不声明站点权限。真实链路尚未验收通过。

## 检查和构建

需要 Node.js 22 或更新版本。

```bash
npm ci
npm run check
```

`npm run check` 会依次做类型检查、单元测试和构建。CI 跑同一条命令。

单独执行：

```bash
npm run typecheck
npm run test
npm run build
```

构建输出在 `dist/extension/`。该目录被 git 忽略，需要本地重新构建。

## 加载扩展（含实验性 ChatGPT 连接器）

1. 运行 `npm run build`。
2. 打开 Chrome 的扩展管理页，启用开发者模式。
3. 加载已解压的扩展，选择 `dist/extension`。
4. 点击工具栏图标，再打开讨论页。

默认未接入适配器和 `[MOCK]` 演示仍不是模型回答。扩展还提供实验性的 ChatGPT 单标签页连接器，但真实链路尚未整体验收，不能把它当作可用的真实连接。「记录未接入尝试」不会访问网站；「运行 MOCK 演示」只在本地生成假数据。导出文件由浏览器下载保存。

## 安全边界

- 不导出 Cookie、密码、私钥或登录令牌，也不绕过登录和验证码。
- 不在用户不知情时改用按量 API。
- 不执行未经授权的对外发送、删除、付款或发布。
- 页面用文本节点显示内容，不把模型正文或导入文件当成 HTML 或指令执行。
- 不可信 JSONL 会校验结构、长度、来源枚举和原型字段。校验失败时不恢复会话。
