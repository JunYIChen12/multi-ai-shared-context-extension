# 多模型共享上下文协作扩展

本仓库用于开发和持续迭代一个面向 Google Chrome 的多模型协作浏览器扩展。

## 用户目标

用户只输入一次问题，扩展通过用户已经登录并购买订阅的 ChatGPT、Grok、Gemini 网页版获取各模型的独立回答，再将不同模型的观点互相同步，用于补充、质疑和交叉验证。

扩展需要在同一个工作界面中展示讨论过程、观点来源、主要分歧和综合结论，并维护可继续追问的共享上下文，减少用户重复提问和手工复制粘贴答案。

## 已确认需求

- 产品形态为 Google Chrome 浏览器扩展。
- 优先复用各家已购买的网页版订阅额度，不默认使用按量付费 API。
- 用户一次提问，可获得多个模型的独立回答。
- 第一轮回答后，各模型能够看到并评论其他模型的观点。
- 共享上下文由扩展统一维护，而不是简单并排展示多个聊天窗口。
- 回答和评论需要标明来源模型及讨论轮次。
- 单个模型失败或超时不能阻塞其他模型。
- 模型讨论必须有停止条件，不能无限循环。

## 尚未确定

- 具体界面采用侧栏、弹窗还是独立扩展页面。
- 网页控制与上下文同步的具体实现技术。
- 共享上下文的存储方式和保留期限。
- 是否采用现有开源项目或进行二次开发。
- 是否需要云端服务或其他中间组件。

以上内容在完成调研和方案评审前，不视为已经确定的技术选型。

## 安全边界

- 不导出或上传用户的 Cookie、密码、私钥和登录令牌。
- 不绕过登录、验证码或网站安全机制。
- 不在用户不知情的情况下切换到收费 API。
- 不执行未经用户授权的对外发送、删除、付款或代码发布操作。
- 浏览器权限应保持最小，并明确说明用途。

## 仓库用途

本仓库只服务于上述用户需求，以及围绕该需求产生的后续功能更新、缺陷修复、文档和版本迭代。与该产品目标无关的功能不在本仓库中扩展。
