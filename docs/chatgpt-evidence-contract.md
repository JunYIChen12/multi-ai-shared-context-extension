# ChatGPT 单轮证据契约

这是离线修复用的判定契约。它不证明当前 ChatGPT 页面已经提供这些字段，也不表示真实网页验收通过。

## 当前迭代的使用前提（用户已接受）

插件处理一轮问题期间，用户不在同一个 ChatGPT 聊天中手动发送消息，也不让其他程序向该聊天发送消息。当前迭代只在这个前提下评估单标签页的自动归属；这是使用约定，不是扩展能从页面独立证明的事实。扩展不能检测到所有违反约定的情况，尤其不能排除外来同文轮次。

这个前提不放宽下面的结构、会话连续性和自然结束条件。若观察到多个新用户轮次、身份冲突、切换会话或证据不可读，仍返回未知或相应失败，不自动重发，也不写成真实成功。验收报告必须注明此前提和剩余的误归属风险；不能宣称一般并发场景已安全，也不能把离线测试当成真实网页验收。

## 归属

发送前只记录结构：轮次 id、角色、顺序、会话地址、生成控件是否可见、错误标记是否可见。不记录旧聊天正文。

本次用户轮次必须是基线里没有的 id，并且只能有一个。它的回复必须是排在这个用户轮次之后、下一个用户轮次之前、同样不在基线里的唯一 assistant id。重挂载保持同一个 id，不能变成新回复。全页数量、最后一个节点、问题文本相同，都不能单独完成归属。

尚未解决的反例：若扩展点击发送后，外来用户轮次先出现并独自得到回复，现有 `submit(): boolean` 与上述结构观察和“本次轮次成功”完全同形；同文问题也无法区分。因此唯一新 user + 邻接 assistant **不是本次提交的因果证明**。真实页面或其他经批准的关联信号尚未核验，不能据此宣称一般归属已验收。

## 终态

正常成功要同时满足：归属成立、该 assistant 内部能读到结束控件、页面生成控件可读且不可见、错误标记可读且不存在、没有观察到停止点击、正文非空并在稳定窗口内保持不变。没见过生成开始也可以成功。

这些条件少任何一个，都不能成功。单独的复制控件、文本稳定或 Stop 消失都不行，三者叠在一起而没有归属或结束控件也不行。

观察到停止控件上的点击后，结果是手停。残留正文不记成完成。没有点击时，不能因为 Stop 消失就猜是手停。

证据不可读、多个候选、信号冲突，或到观察上限仍不充分，结果是未知。可见错误标记是页面错误。这些都不是完成记录。

## 会话地址

只解释三种形状：`https://chatgpt.com/` 是草稿，`https://chatgpt.com/c/<id>` 是正式会话，`/c/local-chatgpt%3A<token>` 是已识别的临时过渡态。其他路径不猜测。临时 token 只用于发现过渡冲突，不写成正式会话 ID；发送前若已经处于过渡态则拒绝发送，发送后遇到它只在既有期限内继续观察。过渡不结束、token 冲突或无法证明正式地址连续时保持未知，不自动重发。

草稿变成 `/c/<id>` 只有在这次提交之后、地址还是 `/` 时已经看到那个新用户轮次，并且之后的 `/c/<id>` 仍带着同一个 id，才延续并钉住该 id。之后再变成另一个 id 就是隔离。根路径上直接看到一个从未在 `/` 出现过的单轮会话，不能当成本次新建。证明不了就未知。

## 并发和取消

同一标签页的内容脚本只用一把锁。另一个讨论页或同一个 requestId 再进来时直接拒绝，不再点击发送。

外层超时会中止对应采集的信号，内容脚本收到取消后停止轮询并放开锁。已经返回的超时记录不会被晚到正文改写。下一次请求重新取基线，不能把上一轮的节点当成自己的新回复。不会自动重发。

共享发送账本中若仍有未匹配发送，同一或未知会话的下一次请求在写入和发送前返回未知；仅当上次发送所在的 `/c/<id>` 与当前 `/c/<id>` 明确不同，才清掉未决状态并允许新请求。上次发送在草稿页时无法仅凭地址证明隔离，仍拒绝重发。这是安全恢复边界，不代表上一轮已成功或已完成。

## 仍未核验的 DOM 假设

当前读取器在现有角色属性之外，还依赖这些未对当前页面验收的假设：

- 同一节点上的 `data-message-id` 是稳定身份。缺失则整页轮次不可读。
- assistant 节点内部的复制按钮使用 `aria-label` 为 Copy / 复制 / Copy response，或 `data-testid="copy-turn-action-button"`。找不到则结束控件不可读。
- 可见的 `[role="alert"]` 表示页面错误；一个都没命中，或只有隐藏节点，不等于已经证明没有错误。隐藏节点不会挡住后面的可见 alert。
- 现有 Stop 选择器零命中不等于已经证明不在生成。命中后才把可见当作生成中、全部不可见当作空闲。这个空闲仍然不是自然结束本身。
- 停止点击只接受本次提交之后、当前可见的 Stop 控件。它仍是页面级控件，还不能证明点的是哪一条回复。
- 地址规则不覆盖语言前缀和其他路径。

这些假设不成立时，结果应是未知或页面错误，而不是成功。真实浏览器兼容仍待后续验证。
